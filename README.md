# 🌆 Site sobre a Cultura da Minha Cidade

Este projeto é um site desenvolvido com o objetivo de apresentar a cultura, história, curiosidades e outros aspectos importantes da minha cidade. A proposta é valorizar o local onde vivo e oferecer uma experiência acessível e visualmente agradável para quem deseja conhecê-la melhor.

## 🚀 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- UI/UX Design (conceitos aplicados)  

## 📌 Funcionalidades

- Página inicial com destaques culturais  
- Seções sobre história, gastronomia, festas populares e pontos turísticos  
- Design responsivo para diferentes tamanhos de tela  
- Navegação simples e intuitiva  

## 📄 Status do projeto

🔧 Em desenvolvimento  
Ainda estou trabalhando na estrutura visual e na organização do conteúdo.

## 🧠 O que estou aprendendo com este projeto

- Organização de layout e hierarquia visual  
- Melhores práticas de HTML e CSS  
- Estruturação de um projeto real do zero  
- Aplicação de conceitos básicos de design de interfaces  
- Responsividade e usabilidade
